# Glosario

| Término | Significado en E-Trading |
|---|---|
| **Core loop** | Lo que el usuario hace cada día y por qué vuelve: lección, quiz, práctica en el mercado y racha |
| **Lección / paso** | Una lección son 4–7 pasos (texto, imagen, vídeo, gráfico interactivo, tarea en el simulador, truco de Lumi) y termina en un quiz |
| **Quiz** | 5–6 preguntas al final de una lección; fallar quita vidas |
| **Test de nivel** (*placement*) | Quiz inicial sin vidas ni feedback que decide en qué unidad empiezas |
| **Vidas** | 5 como máximo; se pierden al fallar en los quizzes y se recuperan 1 cada 4 h |
| **Gemas** | Moneda interna que solo se gana jugando; sirve para recargar vidas y comprar protectores de racha |
| **Racha** | Días seguidos con al menos una lección, un quiz o una operación, en tu zona horaria |
| **Protector de racha** | Salva la racha si fallas un día; se consume solo |
| **XP / nivel** | Puntos de experiencia y nivel, con título en femenino, masculino o neutro |
| **Liga / división** | Competición semanal en grupos de hasta 30; 5 divisiones de Novato a Experto |
| **Rentabilidad ajustada por riesgo** | Rentabilidad semanal corregida por la volatilidad y la concentración de la cartera; evita premiar apostarlo todo |
| **Lumi** | La mascota: guía, avisa y explica, con 7 estados de ánimo; nunca recomienda comprar ni vender |
| **Orden a mercado / límite / stop loss / take profit** | Tipos de orden del simulador (ver `03-mercado.md`) |
| **Aviso de riesgo** | Lumi avisa si una compra deja un activo por encima del 20 % de tu cartera |
| **Stale** | Precio "con retraso": el último conocido cuando el proveedor no responde; se muestra con su hora y un banner ámbar |
| **Fidelidad (F1–F7)** | Criterios medibles de qué significa "replicar el mercado real" |
| **Evento de dominio** | Aviso interno ("orden ejecutada", "quiz terminado") que dispara XP, racha, logros, etc. desde un único sitio |
| **MVP** | La primera versión completa que probarán 20–50 personas (ver `01-producto.md` §7) |
| **Preview** | Enlace de Vercel con la versión en desarrollo (rama `v2`), separado de producción |
