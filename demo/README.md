# E-Trading · Demo interactiva

Maqueta navegable del diseño nuevo (identidad 3a) para enseñar el producto. Es una sola página estática (`index.html`), sin servidor ni base de datos: las cifras son de ejemplo y no se guarda nada.

Se publica sola en Vercel (proyecto `e-trading-demo`, carpeta raíz `demo/`) con cada push a `main` que cambie esta carpeta.
