# Material de la v1 (solo referencia)

No se compila ni se importa. Se conserva para reutilizar ideas y contenido en la v2:

- `clases-contenido.ts`: las 10 clases de Fundamentos ya escritas (material de partida para las unidades 1 y 3).
- `assets.ts` y `brokers.ts`: catálogo de activos y comparativa de brokers.
- `finnhub.ts`, `market.ts` y `fx.ts`: caché de cotizaciones compartida en base de datos, límite de llamadas a Finnhub y tipos de cambio del BCE.
- `schema-v1.sql`: esquema de base de datos de la v1.

El código completo de la v1 sigue en la rama `main`.
